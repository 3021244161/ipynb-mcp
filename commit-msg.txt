DEVIATIONS.md gains the ten divergences the round-3 work introduced or had to
name, each with the reason and the honest blast radius:
- D-022 kernel/interpreter.ts is not in SPEC §8's file list
- D-023 the sidecar DOES create one file (its own kernel connection file, which
  carries an HMAC key). It is now pinned to the OS temp directory and unlinked on
  graceful shutdown / shutdown_all / stdin EOF, and FAILED starts clean up too —
  this repository's own probes had left 16 of them behind before the fix. A hard
  kill can still leave one in the temp dir; it is never written into a user's
  notebook directory
- D-024 unknown argument names are rejected by the strict schemas, which makes
  that failure a protocol error rather than `invalid_arguments` (the alternative
  was silently ignoring the key, which is what SPEC §4.1.11 exists to prevent)
- D-025 timeout now really shuts the kernel down, in that order
- D-026 realpath-based path identity for reuse keys and run locks
- D-027 the transport margin must exceed the sidecar's own worst case, and only
  exec_cell reclaims the process tree
- D-028 the delibate asymmetry between the two write-backs' signal handling
- D-029 a runtime unhandled rejection no longer exits the server
- D-030 the interpreter chain degrades at RESOLUTION time only; an interpreter
  that claims ipykernel but cannot boot one fails with the sidecar's stderr
- D-031 we no longer kill an exited sidecar's tree by pid

QUAL-1: `scripts/check-format.mjs` (zero dependencies) checks the two decidable
properties — tabs and trailing whitespace — and runs as part of `pnpm lint`. It
deliberately does NOT try to validate block nesting: continuation lines and
object literals legitimately indent deeper, so such a heuristic would have to be
suppressed, and a suppressed check protects nothing. prettier was not added
because a new dependency needs a human decision first (AGENTS §11).

Also: README's known limitations state the four behaviours above that a user can
actually observe; AGENTS §4's tree is rewritten from `git ls-files src` (the old
one still listed files that never existed and omitted four that did); the
sidecar's module rule is corrected rather than left as an absolute it never met.
